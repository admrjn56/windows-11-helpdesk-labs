# Windows 11 Help Desk Lab Portfolio

This repository documents 15 hands-on Windows 11 Help Desk labs completed in a virtualized Windows environment.

The purpose of this project is to demonstrate practical Tier 1 Help Desk and Desktop Support skills through troubleshooting scenarios involving Windows administration, networking, permissions, system services, performance, event logs, and workstation deployment.

## Lab Environment

- Windows 11
- VMware Fusion
- macOS host system
- PowerShell
- Command Prompt
- Windows Terminal
- Event Viewer
- Device Manager
- Task Manager
- Windows Services
- DiskPart
- DISM
