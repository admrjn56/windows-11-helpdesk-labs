# Lab 01: Local account password reset

## Environment

Windows 11 virtual machine in VMware Fusion.

## What I observed

An initial password change from an ordinary PowerShell session returned System error 5 (Access is denied). The elevated command completed successfully. A later screenshot shows the local jsmith account enabled with a recent password change and last logon. The screenshot that exposed the test password is intentionally excluded.
